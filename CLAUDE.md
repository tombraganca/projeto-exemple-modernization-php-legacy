# Projeto de modernização (Fusion Modernization)

Este repositório guarda só código:

- `legacy/`: código do sistema legado. **Só leitura**: nunca crie, edite ou apague arquivos nele.
- `demo/`: o sistema modernizado, escrito pelos agentes card a card.
- `.claude/`: agentes e skills do Fusion.

Os artefatos do processo (descoberta, regras de negócio `RN-`, decisões `ADR-`, jornadas `JOR-`,
cards `CARD-`, dúvidas `Q-`) não ficam aqui: o app passa a pasta deles para o agente.
Commits no repositório citam o card (`CARD-012: …`).
